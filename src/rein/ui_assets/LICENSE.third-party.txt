Third-party code redistributed inside app.js
============================================

`app.js` is a bundle. Alongside this repository's own sources under `ui/`, it contains
React, react-dom and scheduler, minified and inlined by esbuild. The `@license React`
comments esbuild preserved in the bundle carry the copyright and point at "the LICENSE
file in the root directory of this source tree" — a file that exists in React's own
repository and not in this wheel. This is that file, shipped beside the bundle so the
permission notice travels with the copy, as the MIT licence requires.

The rest of `rein` is Apache-2.0 (see the LICENSE in this distribution's metadata);
nothing here changes that.
